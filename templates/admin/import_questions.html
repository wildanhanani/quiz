Import Questions from CSV

📋 CSV Format Instructions

Your CSV file must have the following columns (header row required):

✨ Delimiter Support: File bisa menggunakan koma (,) atau titik koma (;) sebagai pemisah. Sistem akan otomatis mendeteksi!

  • category - Category name (e.g., "TWK")
  • category_description - (Optional) Category description
  • question - The question text
  • order - Question order number (e.g., 1, 2, 3...)
  • choice_1 - First answer choice
  • choice_2 - Second answer choice
  • choice_3 - Third answer choice
  • choice_4 - Fourth answer choice
  • choice_5 - (Optional) Fifth answer choice
  • correct_answer - Number of correct choice (1, 2, 3, 4, or 5)

💡 Catatan: choice_5 bersifat opsional. Anda bisa menggunakan 4 atau 5 pilihan jawaban.

Example CSV Content (with comma):

category,category_description,question,order,choice_1,choice_2,choice_3,choice_4,correct_answer
TWK,Tes Wawasan Kebangsaan,Pancasila terdiri dari berapa sila?,1,3,4,5,6,3
TIU,Tes Intelegensi Umum,Berapa hasil 5 x 5?,2,20,25,30,35,2

Example CSV Content (with semicolon): 

category;category_description;question;order;choice_1;choice_2;choice_3;choice_4;correct_answer
TWK;Tes Wawasan Kebangsaan;Pancasila terdiri dari berapa sila?;1;3;4;5;6;3
TIU;Tes Intelegensi Umum;Berapa hasil 5 x 5?;2;20;25;30;35;2

Example with 5 choices (comma):

category,category_description,question,order,choice_1,choice_2,choice_3,choice_4,choice_5,correct_answer
TWK,Tes Wawasan Kebangsaan,Siapa presiden pertama RI?,1,Soekarno,Soeharto,Habibie,Megawati,SBY,1
TIU,Tes Intelegensi Umum,Hasil 10 + 5 adalah?,2,10,12,15,18,20,3

Example with 5 choices (semicolon):

category;category_description;question;order;choice_1;choice_2;choice_3;choice_4;choice_5;correct_answer
TWK;Tes Wawasan Kebangsaan;Siapa presiden pertama RI?;1;Soekarno;Soeharto;Habibie;Megawati;SBY;1
TIU;Tes Intelegensi Umum;Hasil 10 + 5 adalah?;2;10;12;15;18;20;3
