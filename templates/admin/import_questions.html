Import Questions (CSV / ZIP)

📋 Instructions

Option 1: CSV Only (Text Only)

Upload a standard .csv file for text-only questions.

Option 2: ZIP File (With Images) 📸

To include images, create a .zip file containing:

  1. Your .csv file
  2. All your image files (jpg, png)

In your CSV, add an image column with the exact filename (e.g., soal1.jpg).

CSV Column Format:

  • category - Category name (e.g., "TWK")
  • category_description - (Optional) Category description
  • question - The question text
  • image - (Optional) Image filename (e.g., 'question1.jpg') - Requires ZIP upload
  • order - Question order number (e.g., 1, 2, 3...)
  • choice_1 - First answer choice
  • choice_2 - Second answer choice
  • choice_3 - Third answer choice
  • choice_4 - Fourth answer choice
  • choice_5 - (Optional) Fifth answer choice
  • correct_answer - Number of correct choice (1-5)

💡 Note: Use semicolon (;) delimiter if your text contains commas.

Example CSV Content:

category;question;image;choice_1;choice_2;choice_3;choice_4;correct_answer
TWK;Gambar di samping adalah?;pancasila.jpg;Bintang;Pohon;Rantai;Padi;1
TIU;Hitung hasil berikut;rumus1.png;10;20;30;40;3
