Opsi 1: CSV atau Excel (Soal Teks)

Upload file .csv atau .xlsx untuk soal tanpa gambar.

Butuh format siap isi? Download template Excel .

Opsi 2: File ZIP (Dengan Gambar) 📸

Untuk menyertakan gambar, buat file .zip yang berisi:

  1. File .csv atau .xlsx Anda
  2. Semua file gambar yang dipakai (jpg, png)

Di file Anda, isi kolom image dengan nama file yang sama persis, misalnya soal1.jpg.

Format Kolom:

  • parent_category - Opsional. Nama kategori utama, misalnya "CPNS"
  • category - Nama kategori, misalnya "TWK 2024"
  • category_description - Opsional. Deskripsi kategori
  • question - Teks soal
  • explanation - Opsional. Pembahasan jawaban
  • image - Opsional. Nama file gambar, misalnya question1.jpg. Wajib upload via ZIP
  • order - Nomor urut soal, misalnya 1, 2, 3
  • choice_1 - Pilihan jawaban pertama
  • choice_2 - Pilihan jawaban kedua
  • choice_3 - Pilihan jawaban ketiga
  • choice_4 - Pilihan jawaban keempat
  • choice_5 - Opsional. Pilihan jawaban kelima
  • correct_answer - Nomor pilihan jawaban yang benar, 1-5

Template XLSX: Admin bisa download workbook siap pakai berisi header, satu contoh baris, dan sheet panduan.

💡 Catatan: Gunakan delimiter titik koma (;) jika teks Anda mengandung banyak koma.

Contoh Isi Tabel:

parent_category;category;question;explanation;image;choice_1;choice_2;choice_3;choice_4;correct_answer
CPNS;TWK;Gambar di samping adalah?;Bintang adalah lambang sila pertama.;pancasila.jpg;Bintang;Pohon;Rantai;Padi;1
CPNS;TIU;Hitung hasil berikut;9 + 1 = 10.;rumus1.png;10;20;30;40;1
